Architecture 2 — MAI real-time + DeepSeek

MAI-Transcribe-1.5 streams through Voice Live while the call is in progress, then one strict-schema DeepSeek call in Microsoft Foundry returns a PII-safe summary.

Real-time, not post-call. Because audio is transcribed as it is spoken, the transcript lands about three-tenths of a second after the caller hangs up. Architecture 3 runs the same models on the finished recording instead, and pays a post-call wait for it. DeepSeek here returns only {"summary": string} — there is no redacted transcript and no entity list, so this path is not a drop-in replacement for full transcript redaction.
Numbers read from the checked-in stereo benchmark result (504.168s call, 989-word reference).
