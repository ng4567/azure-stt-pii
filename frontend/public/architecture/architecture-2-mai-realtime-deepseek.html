Real-time, not post-call. Because audio is transcribed as it is spoken, the transcript lands about a fifth of a second after the caller hangs up. Architecture 3 runs the same models on the finished recording instead, and pays a post-call wait for it. DeepSeek here returns only {"summary": string} — there is no redacted transcript and no entity list, so this path is not a drop-in replacement for full transcript redaction.
