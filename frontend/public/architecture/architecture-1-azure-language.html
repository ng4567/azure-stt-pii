Current state — Azure Speech + Azure AI Language

The stack most contact centres run today. Azure Speech transcribes the call as it happens, then Conversation PII and conversation summarization run concurrently on the transcript. It is the only path that returns a redacted transcript and a typed entity list — and its summarization feature is scheduled to retire on March 31, 2029.

The managed baseline. Redaction is decided by a dedicated Azure AI Language model rather than a general-purpose model under a prompt, and both Language calls are issued in parallel, so their endpoint times overlap instead of accumulating. That governance comes at a price: it is the more expensive path per call and the less accurate transcript. Because it emits a full redacted block and a typed entity list, it is the only path that can be scored for PII precision and recall.
Call-processing figures are read from the checked-in stereo benchmark result (504.168s call, 989-word reference), at Azure list price before any negotiated discount. The analytics half is a deployment blueprint, not a measured benchmark.
