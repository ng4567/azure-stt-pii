Architecture 1 — Azure Speech + Azure Language

The fully managed, first-party path: Azure Speech transcribes the call as it happens, then Conversation PII and Conversational Summarization run concurrently on the transcript. It is the only architecture that returns a redacted transcript and an entity list.

The managed baseline. Redaction is decided by a dedicated Azure AI Language model rather than a general-purpose LLM under a prompt, and both Language calls are issued in parallel, so their endpoint times overlap instead of accumulating. That governance comes at a price: this is the most expensive path per call ($0.031069 discounted) and the least accurate transcript of the three. Unlike Architectures 2 and 3, it returns a full redacted block and a typed entity list, so it is the only path that can be scored for PII precision and recall.
