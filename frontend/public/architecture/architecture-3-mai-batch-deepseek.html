The pipeline is serialized after the recording is complete, so the transcript arrives 16.9s after hang-up instead of alongside the call — the price of needing no live streaming session. Everything downstream is byte-for-byte the shared Architecture 2 path, so the only variable being measured is streaming versus batch.
